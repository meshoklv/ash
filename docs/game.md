# «Ash: Dark Souls» — одна игра от титула до Храма Огня (`src/game/ds/`)

*15.10.2026, интегратор ночи. Пометки: **[проверено]** — прогон/лог/кадр, **[версия]** — гипотеза, **[придумал]** — решение без опоры на данные, **[урезание]** — сознательно проще DS1.*

EBOOT `ash_ds` («Ash: Dark Souls», в дистрибутиве — `PSP/GAME/ASHGAME`). Цепочка:

титул «НАЖМИТЕ ЛЮБУЮ КНОПКУ» → главное меню (Продолжить / Новая игра / Настройки / Выйти) → создание персонажа (имя, пол, 10 классов, дар, причёска) → загрузка → **Северное Прибежище** целиком (то же, что `ash_asylum`, [asylum.md](asylum.md)) с моделью, снаряжением и числами выбранного класса → START: пауза, инвентарь, снаряжение, статус, настройки; костёр: меню костра; смерть: «ВЫ ПОГИБЛИ» — всё экраны `src/menu` → ворон → экран загрузки → **Храм Огня** m10_02 (Прибежище выгружено) → костёр, Разочарованный воин, лут, закрытые выходы → автосейв → «Продолжить» после перезапуска.

## 2. Решения

- **Класс = модель + числа.** Тело игрока — `cls_<строка>_<m|f>.ashc` из кука меню (тот же 30-костный скелет, что у `knight.ashc`, анимации рыцаря подходят) **[проверено: число костей сверяется при замене, кадры]**. HP/энергия — `itm_calc` по атрибутам класса; AR правой руки, защита щита и стабильность — из снаряжения класса.
- **[урезание] Мувсет один на все классы.** В `combat.ashcb` есть только Длинный меч и Рыцарский щит (окна ударов, клипы). Любой класс бьёт клипами длинного меча, а числа (AR, % блока, стабильность) берутся из его оружия.
- **[урезание] Старт в Прибежище — полный набор CharaInitParam**, а не рукоять без щита, как в DS1: модель класса уже держит этот набор, а бои автопилота до костра 2 рассчитаны на щит. Фляга эстуса из набора убрана — её даёт событие у Оскара.
- **Двери с ключами** проверяет `src/event` по своим флагам выданных предметов; ключ дополнительно кладётся в инвентарь (видно в меню).
- **Храм Огня без скрипта событий** (`cook_events` для m10_02 не кукался): костёр, воин, лут и выходы — логика в `ds_main.c` (`fl_step`). Костёр — первое действие «Зажечь», дальше «Отдохнуть» (сесть → через 1 с перезагрузка: HP/эстус, затем автосейв). Воин — реплика по кнопке действия, по порядку; после последней — снова с третьей **[придумал]**. Лут — регионы `TREASURE` из `ents` (12 точек), `itm_award_lot`. Выходы — невидимые стены в коллизии зоны (кук агента Храма) + сообщение «Путь закрыт» **[придумал]**. Состояние Храма (взятый лут, костёр, разговор) — биты `SaveGame.flags`.
- **Выгрузка Прибежища:** мир, коллизия, события, полые, Демон, хост Lua, быстрые списки зоны и VRAM. Куча в эмуляторе: Прибежище 11 685 КБ → после выгрузки 2 032 КБ → Храм 6 141 КБ **[проверено: лог `heap in use`, эмулятор, не железо]**.
- **VRAM при смене зоны** раскладывается заново: текстуры зоны по частоте использования, затем персонажи (тело класса, полый, Демон или воин).
- **Плюх:** урон окна модуля 71,2 × 4 = 285 **[версия: DS1 бьёт плюхом намного сильнее строки AtkParam, совпадает с прежней заглушкой 4 × AR]**; если окно не попало, остаётся прежняя проверка дистанции при приземлении.
- **Туман и дальность Храма** — 25…120 м, `0x504846`, дальность 82 м **[придумал, `docs/firelink.md` §2]**.

## 3. Автопилот (`demo.txt`) и прогоны

`scripts/shoot-ds.sh <out> <сценарий> [dump_every] [max_frames] [эмулир. секунд] [keep_ms]` — стейдж `build/stage-ds-$DS_TAG`, карта памяти `build/ds-ms-$DS_TAG`, эмулятор через `scripts/emu-slot.sh` + shm-shim. Именованные кадры `sh_<имя>.raw` → PNG.

| Сценарий | Что делает |
|---|---|
| `full` (A) | титул → «Новая игра» → Рыцарь → маршрут `route` из `asy_auto.c` (весь Прибежище, костёр 1 через меню костра `src/menu`, Демон, плюх, победа) → ворон → Храм: подойти к воину, 2 реплики, лут с трупа, зажечь костёр, отдохнуть (меню), пауза → инвентарь → снаряжение → статус |
| `hollow`, `boss`, `death` | то же создание персонажа, дальше сценарий `asy_auto.c`: дуэль с полым (блок, отскок, парирование, рипост), бой с Демоном со снимка у костра 2 (плюх; снимка нет — сначала маршрут до костра 2, он же пишет снимок; смерти возрождают у костра 2), смерть → «ВЫ ПОГИБЛИ» → костёр → пятно душ |
| `continue` (D) | второй запуск на той же карте памяти: «Продолжить» → зона/костёр/инвентарь из сейва → статус, инвентарь |
| `firelink` | отладка: сразу после создания — ворон и Храм |

Результаты — the status design notes (строка M7) и кадры `~/ash-assets/shots/night-final/` (вне git).
