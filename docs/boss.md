# Босс: Демон Прибежища (c2232)

Код: `tools/cook_boss.py`, `tools/tae_ds1.py`, `src/boss/` (`boss.h/.c` — тело, анимация, машина состояний, HUD;
`boss_ai.h/.c` — мост к Lua-хосту `src/ai`; `bosstest.c` — тестовый EBOOT). Запуск теста: `scripts/shoot-boss.sh`.

## 3. ИИ

Два режима, переключаются `boss.ai_mode`:

1. **Lua (основной, родной скрипт) [проверено в PPSSPP]:** `boss_ai_attach()` подключает тело к хосту `src/ai`
   : 50 чанков aiCommon + `223200_battle.luac`, перепакованные в 32 бит/float. Лог прогона
   `~/ash-assets/shots/boss-lua-1724c/run/run.log`: думки Act01 (3007 издалека), Act03 (3006), комбо 3003→3013,
   FindAttack → шаг назад 701, фаза балкона 3020 → 3021×3 → 3023 — в том порядке, как в скрипте. Одна
   `LUA ERROR … compare number with nil` на Act15 — это ванильный скрипт (Act15/Act16 возвращают nil), подцели
   при этом уже добавлены, так и задумано.
2. **Машина состояний на C (запасной, без Lua):** `boss.c`, функции `think()`/`act()` повторяют
   `MiniGreaterDemon223200Battle_Activate`: те же условия (регионы 1812350/351/352/990/996, сферы наблюдения
   вокруг думми 3 и 4 радиусом 2 и 3 м, корзины дистанций 11,5 / 7 / 4,2 / 1,5 м) и веса, дистанции подхода
   (Att3000 9,6; Att3001 8; Att3002 6,6; Att3003 6,4; Att3006 1,5; Att3007 11,9; Att3014 8), комбо с теми же
   вероятностями (10/10/80, 10/90), AdjustSpace (20% — шаг вбок 2,5 с), прерывания FindAttack_Step (≤3 м, 5%),
   Damaged_Step (≤3 м, 5%), UseItem_Act (≤15 м, 15%, наказание по дистанции). Источник — декомпиляция
   `~/ash-assets/ai/m18_01_00_00/223200_battle.lua` (+ `.lst`), в git только числа.

Нативное поведение (нет в данных) — [версия]: GetDist = расстояние между телами (центры − радиусы; скрипт
использует отрицательные диапазоны, напр. 3008 −3…0); CommonAttack доворачивает до 20° или 1,5 с, потом атака;
бег, если цель дальше AppDist + 6 (DashDist в скриптах); в окнах TAE 224 босс доворачивает за игроком с указанной
скоростью (210–500 °/с); следующий удар комбо стартует в точке отмены (самый ранний флаг 78/79/86).

## 4. Интерфейс для игры (`src/boss/boss.h`)

```c
Boss boss;                              // ~8 КБ (позы + матрицы 31 кости), статический
boss_load(&boss, chr, n, anim, n, ashboss, n, name_tex, n);   // буферы из ash_load_file, живут всю зону
boss_reset(&boss, NULL, 0);             // на точку MSB, полное HP, ждёт игрока (повторно — после смерти игрока)
boss_enter_drop(&boss);                 // первая встреча: падение с потолка (9060), неуязвим во время входа
// каждый шаг 1/30 с:
BossWorld w = { .player = {...}, .player_radius = 0.35f, .player_dead = 0,
                .collide = my_pcol_move /* или NULL: зажим в коробке зала */, .ctx = &col };
boss_tick(&boss, &w, DT);               // или boss_ai_tick(&ba, &w, DT) в режиме Lua
int n = boss_hits(&boss, hits, 8);      // объёмы ударов в мире: a,b,radius,atk,swing (один удар на swing)
boss_hurt_capsule(&boss, a, b, &r);     // тело для ударов игрока
boss_take_hit(&boss, dmg, poise, BOSS_HIT_PLUNGE /* или NORMAL */);
boss_event(&boss, BOSS_EV_PLAYER_ATTACK / BOSS_EV_PLAYER_ITEM);   // прерывания скрипта
boss_draw(&boss);                       // 3D-проход, GU_LIGHTING включён
boss_hud_draw(&boss);                   // 2D: имя «Демон Прибежища» + полоса HP (задержанная жёлтая часть)
boss_defeated(&boss);                   // смерть доиграна: души, туман, флаг события
```

**Боёвка (`src/combat`):** `cook_combat.py` уже содержит kind c2232. Если босс — CbActor, игра пишет
`bones = (float*)boss.world` (модельное пространство, 31 кость), `anim_id = boss_anim_id(&boss)` (3000…),
`anim_t = boss.t`, и тогда удары/урон считает боевой модуль, а `boss_hits()` не нужен. `actor->req_anim` для
демона игнорировать (реакций нет).

**События (`src/event`):** первая встреча = `boss_enter_drop` при входе игрока в зал (у DS1 — EMEVD m18_01;
игрок убегает в дверь `BREG_EXIT` 1812320 — бой без тумана, полоска HP есть). Второй бой: игрок на балконе
(1812350) → скрипт сам играет 3020/3021, игрок прыгает → `boss_take_hit(..., BOSS_HIT_PLUNGE)` с уроном
плунж-атаки из боёвки (AttackType 62). Победа → `boss_defeated()`.

## 6. Не сделано / риски

- В игру (`src/game/main.c`) босс не встроен — это зона интеграции; интерфейс выше.
- Плунж-урон, урон по игроку, i-frames игрока — в тесте заглушки; настоящие — боевой модуль.
- `boss.ashanim` 1,37 МБ ОЗУ — много для зоны (бюджет ≤10 МБ на зону, [оценка]); урезать до ~25 клипов или ключи
  15 Гц, если не влезет на железе.
- Смысл 1500/1750 (падение/приземление в яму при обрушении пола), 2520–2522, 3500, 9000 — [версия]; обрушение пола
  (регион 1812311/1812400, Демон-отступник) — в S1 не делается.
- Интерполяция окон TAE по накопленному времени — да; hitstop/отдача — у боевого модуля.
