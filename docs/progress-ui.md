# Прогрессия и интерфейс (src/progress, src/ui)

**На 14.10.2026.** Эстус, души, пятно душ, смерть → «ВЫ ПОГИБЛИ» → костёр, отдых у костра (сесть / меню / встать), сохранение; HUD в раскладке DS1, шрифт с кириллицей, тексты из русской локализации DSR, баннеры из текстур DSR. Тест-EBOOT `ash_hudtest` гоняет всё это поверх зала Демона. Пометки: **[проверено]** — командой/данными, **[версия]** — гипотеза, **[придумал]** — наше решение.

## Кто чем владеет (без дублей с соседними модулями)

| Что | Модуль | Как прогрессия с ним говорит |
|---|---|---|
| HP, стамина, урон, обнаружение смерти | `src/combat` (`CbActor.hp/hp_max/sp`) | `prg_bind_hp(&p, &actor.hp, &actor.hp_max)` — эстус и отдых пишут в HP актёра; смерть игрока `CB_EV_DEATH` → `prg_player_died(pos)`; смерть врага → `prg_add_souls(npc->souls)` (NpcParam.SoulReward) |
| Костры (объекты, флаги, точка возрождения), респаун врагов, подсказки, полоса босса | `src/event` | `EV_CMD_REST` → `prg_rest_begin`; `EV_CMD_RELOAD` → `prg_on_reload` (+ переставить игрока в `ev_respawn`); `EV_CMD_KILL a` → `prg_add_souls(a)`; `EV_CMD_KILL_BOSS` → `prg_banner(IMG_VICTORY)` + души; `EV_CMD_BONFIRE_LIT` → `prg_banner(IMG_BONFIRE_LIT)`; `EV_CMD_BANNER 900003/4/5` → `IMG_AREA_ASYLUM/IMG_DIED/IMG_VICTORY`; `EV_CMD_BOSS_BAR` → `HudFrame.boss_on/boss_name`; `EV_CMD_ITEM text` → `HudFrame.toast_text`; `ev_prompt()` → `HudFrame.prompt`; `EV_CMD_SAVE` → запись сейва |
| Проигрывание клипов, движение, камера | `src/game` | по `p.req & PRG_REQ_ANIM` играет `prg_anim_name[p.anim]` из `knight_prg.ashanim`; пока `prg_locked()` — ввод геймплея и движение выключены |

## Как вызывать из игры

```c
#include "progress.h"   /* + prg_hud.h, hud.h, ui.h, save.h */
UiRes ui; Hud hud; Progress prog;
ash_load_file("ui.ashui", &f, 0, 0); ui_load(&ui, f, n);
anim_load(&prg_anim, file_knight_prg, n);             /* второй AnimSet, кости = кости рыцаря */
prg_init(&prog, 0);                                   /* PrgCfg по умолчанию: prg_default_cfg */
prg_bind_hp(&prog, &player.hp, &player.hp_max);       /* CbActor игрока */
for (a = 1; a < PRG_ANIM_COUNT; a++) prg_set_clip_len(&prog, a, anim_duration(&prg_anim, anim_find(&prg_anim, prg_anim_name[a])));
hud_init(&hud, &ui);
/* загрузка: save_read_file(SAVE_PATH, buf, cap, parts, SAVE_MAX_PARTS) -> prg_save_read(PRG1) + ev_save_read(EVT1) */

/* каждый шаг 1/30 с */
PrgInput in = { .pos = {player.pos...}, .item = act.pressed & ACT_ITEM, .up/.down = d-pad, .confirm = ACT_INTERACT,
                .cancel = ACT_MENU, .busy = player in roll/attack/stagger };
prg_tick(&prog, &in, DT);
if (prog.req & PRG_REQ_ANIM)   play_forced(prg_anim_name[prog.anim], prog.anim_loop);
if (prog.req & PRG_REQ_RELOAD) ev_player_died(ev);     /* -> EV_CMD_RELOAD -> prg_on_reload + ev_respawn */
if (prog.req & PRG_REQ_SAVE)   { SavePart p[2] = {{SAVE_TAG_PROGRESS, blob, prg_save_write(&prog, blob, cap)},
                                                  {SAVE_TAG_EVENTS, evb, ev_save_write(ev, evb, cap2)}};
                                 save_write_file(SAVE_PATH, p, 2); }
if (prg_locked(&prog)) { /* никакого движения/атак */ }

/* кадр, после 3D */
HudFrame hf; hud_frame_clear(&hf); prg_fill_hud(&prog, &ui, &hf);
hf.sp = player.sp; hf.sp_max = player.sp_max;
hf.boss_on = ...; hf.boss_hp = demon.hp; hf.boss_hp_max = demon.hp_max; hf.boss_name = ui_str(&ui, S_BOSS_ASYLUM);
hf.prompt = prg_locked(&prog) ? 0 : ev_prompt(ev);
hud_tick(&hud, &hf, DT);
ui_begin(); if (prog.stain_on) hud_draw_stain(&hud, &vp, prog.stain_pos); hud_draw(&hud, &hf); ui_end();
```

`ui_begin()` выключает глубину/туман/свет/отсечение и включает смешивание; `ui_end()` возвращает глубину и отсечение, смешивание выключено. Цвета — ABGR (`0xAABBGGRR`). Запросы хуков (`prg_rest_begin`, `prg_player_died` …) выходят из ближайшего `prg_tick` вместе с его собственными (`req` живёт до следующего тика).

## HUD (480×272)

Раскладка DS1 **[придумал: пропорции 1080p → 272 по глазу]**: HP (красная, 0,22 px на очко: 572 → 126 px) и стамина (зелёная, 1,35 px: 88 → 119 px) слева сверху, жёлтый «след» потерянного HP держится 0,6 с и стекает; крест быстрых слотов слева снизу, эстус — нижний слот (иконка из DSR + число); души справа снизу, прибавка «+N» висит ~1 с и «накатывается» в счётчик; полоса босса снизу по центру с именем из FMG; подсказка действия «× Отдохнуть у костра» по центру; тост сверху; баннер — тёмная полоса через экран + текстура; экран загрузки — как в DS1, предмет и его описание (Фляга с Эстусом).

## Шрифт и тексты

- **Шрифт: DejaVu Serif** (`/usr/share/fonts/truetype/dejavu`), лицензия Bitstream Vera + public domain — свободно встраивать и распространять. 12 и 17 px, атлас 256×256, 4 бита альфы (CLUT4, 16 уровней), 346 глифов: ASCII, весь русский алфавит с Ёё, «»—–…№°×. Шрифт DSR (`font/`) не брали: его нет в распакованной копии, а атлас из текстур был бы только для личного использования.
- **Тексты: русская локализация DSR есть** (`msg/RUSSIAN`) — **[проверено]**. Источник каждой строки пишется в `ui.json` (`string_source`). Примеры: «Отдохнуть у костра» (menu fmg 30 / 10010183), «Разжечь костер» (10010182), «Выйти» (15000005), «Новый уровень» (15000100), «Души» (fmg 76 / 101041), «Фляга с Эстусом» (item fmg 10 / 201), «Демон Прибежища» (item fmg 18 / 2232), «Северное Прибежище Нежити» (item fmg 19 / 1810), «Загрузка...» (fmg 92 / 47102). Своих строк 4: «Сохранение...», «Игра сохранена», «Души возвращены», и текстовые дубли баннеров (перевод свой; нужны только если текстур нет). `--lang ENGLISH` — английские FMG, баннеры тогда рисуются шрифтом.
- **Баннеры — текстуры DSR** (`menu/RUSSIAN/menu_local.tpf`): «ВЫ ПОГИБЛИ», «ВРАГ ПОВЕРЖЕН» (Menu14), «КОСТЕР ЗАЖЖЕН» (Menu15), «Северное Прибежище Нежити» (Menu20). Вырезаются по альфе в полосе, «ВЫ ПОГИБЛИ» лежит на непрозрачной чёрной подложке — альфа из яркости. 240×(20–32) px, CLUT8, по 8–16 КБ.
- **Иконки эстуса** — `menu/menu_0.tpf` Icon20, сетка 12×12, индекс = GoodIcon − 2000 (2005 полная, 2004 пустая) **[проверено глазами]**; иконки в ячейках не по центру, поэтому вырезается полоса непрозрачных столбцов, ближайшая к центру ячейки.

## Сохранение

Файл `ash.sav` рядом с EBOOT (cwd: `ms0:/PSP/GAME/ASH/ash.sav`, в headless — каталог стейджинга). Формат v1: `"ASHS"`, версия, число частей, {тег, размер}, данные (выравнивание 4), CRC-32. Части: `PRG1` (52 Б: души, эстус, смерти, пятно, флаги, HP) и `EVT1` (блоб событий `ev_save_write`). Запись атомарная (tmp → rename; без rename — перезапись с CRC). Сейв во время смерти уже содержит смерть (души в пятне) — выход из игры на экране смерти души не спасает, как в DS1. **Не `sceUtilitySavedata`** **[придумал]**: тому нужен цикл утилиты и PARAM.SFO; для среза хватит файла, на XMB сейв виден не будет.
