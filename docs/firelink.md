## 6. Что перенести в общий кукер (`tools/cook_world.py`) — сейчас переопределено в обёртке

1. **Кости кусков карты.** Куски с несколькими костями FLVER (m10_02: m5000–m5064 трава/плющ, m5010/m5020/m5050
   …) хранят вершины в пространстве **кости**, одна сетка = несколько экземпляров. Правильно: для каждой вершины
   `bone = mesh.bone_indices[vertex.bone_indices[0]]`, позиция × armature-transform этой кости **[проверено: m5061B2
   — 3 пучка травы на 3 костях; m5001B2 кость 0 = куст у костра (−44,7, −59,1, 56,6)]**. `cook_world.load_piece_batches`
   этого не делает — такие куски лежат кучей в начале координат. Вероятно, это же причина «m5001B1 в бинд-позе висит в
   воздухе» в m18_01 **[версия]**.
2. **Обрезка по коробке** (зона = часть большой карты): треугольники по центроиду внутри коробки — ближний мир,
   снаружи в пределах ~200 м — дальнее кольцо `BF_FAR` с бюджетом ~800 и без альфа-карточек.
3. **Отключаемые хардкоды m18_01**: сущность 1810800/c2500 в персонажах, `篝火復活ポイント` → param костра, «яма»
   (`pit_box` вместо «вне коробки»), `FLOOR_PLATES`, игрок/цель в `cook_pcol` (`c2232_0000`). Нужны поля конфига зоны:
   `keep_box`, список стартовых персонажей (по EMEVD), RESPAWN → объект костра (здесь 1021960), выходы.
4. **Невидимые стены выходов** — доп. части коллизии через `load_parts` (как `floor_plate_parts`).
5. **Тесселяция под guard band**: `EdgeLimit(e_min=3)` на открытой площадке утраивает упрощённую сетку (11 → 31 тыс.),
   на форму остаётся ~6 % исходника — отсюда «осколки». Здесь `e_min 4, k 1,2, reach 3` + `lod_far_frac 0,5`,
   `lod_far_edge 10`: упрощённой сетки вдвое больше при том же итоге.
6. **Небо**: DS1-текстуры неба тёмные (HDR; `m10_sky_02` средний RGB 26/26/32) — перекук ярче (гамма 0,6 × 1,5),
   CLUT8 256 px, цвет вершин 1,0 вместо 0,35 (иначе небо чёрное).
7. **Осветление текстур карты** под GE (гамма 0,72 × 1,12) для открытых зон.
8. **Мипы для `.ashw`**: `write_mips()` пишет `.ashmip` по индексам `WorldTex` пака; рисовать — `render_tex_bind`
   (копия `world_draw` в `src/firelink/test/main.c`).
9. Ключ `quality_near/far` нового кода интегратора (буст кусков по осколкам/дырам) для Храма **выключен**: он дал
   траве m5061–m5064 ×4–×6 треугольников за счёт стен аркады (кадры хуже) **[проверено: кадры до/после]**. Обёртка
   берёт новые ключи конфига `cook_world.M18` по умолчанию, свои — поверх.

## 7. Не сделано / ограничения

- Только тест-EBOOT: в игру (`src/game`, состояния/переход из Прибежища) не встроено — зона интегратора.
- События EMEVD m10_02 (`cook_events`) не кукались: костёр/лут/выходы — только точки и роли в `ents`.
- Петрус и Анастасия — только точки, модели не кукались; лицо воина — заглушка `FC_M_0000`.
- Качество: упрощение ~13 % исходника (коэффициент кука 0,127), дальний LOD — половина от этого; часть стен руин «зубчатая», есть мелкие щели (в них видно небо/облака);
  в обзоре сверху много грубых плоскостей; дерево m7000 и верхушки (до y +5) мешают камерам выше −40.
- Камера облёта отталкивается от коллизии сфера-кастом (как в игре); на одном участке прижимается к стене.
- Невидимые стены не проверены проходом; капсулой по коллизии зоны никто не ходил.
- Все числа производительности — PPSSPP + модель PSP-est, без железа.
