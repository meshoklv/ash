# Меню в стиле DS1 (src/menu)

**На 14.10.2026.** Титул «НАЖМИТЕ ЛЮБУЮ КНОПКУ» → главное меню → создание персонажа (имя, пол, все 10 классов, дар, 4 причёски, вращающееся 3D-превью класса в стартовой броне) → внутриигровые меню (полоса START, инвентарь, снаряжение, статус, настройки, костёр, новый уровень, «ВЫ ПОГИБЛИ»). Тексты — русская локализация DSR (FMG), картинки — текстуры меню DSR. Пометки: **[проверено]** — командой/прогоном, **[версия]** — гипотеза, **[придумал]** — наше решение.

В игру **не встроено** (идёт интеграция Asylum отдельной задачей): рецепт подключения — ниже. Тест-EBOOT `ash_menutest` проходит все экраны сам.

## Подключение к игре (для интегратора)

1. Корневой `CMakeLists.txt`: `add_subdirectory(src/menu)`; исполняемому файлу — `target_link_libraries(... ash_menu)`. `ash_menu` берёт из исполняемого файла `chr.c`, `anim.c` (их даёт `ash_boss`) и `scene.c` (`ash_load_file`).
2. Рядом с EBOOT: `menu.ashui`, `menu.ashcls`, `menu_idle.ashanim`, `cls_*.ashc`, `head_*.ashc` (всё из `~/ash-assets/cooked/menu`).
3. Код:

```c
#include "menu.h"
static Menu menu;                                   /* состояние с позами/матрицами превью - не на стеке */
menu_init(&menu);                                   /* 0 = ок */
menu_set_scene_light(&menu, dir, diffuse, ambient); /* свет игры: превью меняет LIGHT0 и восстанавливает этот */
menu_set_has_save(&menu, save_exists);              /* «Продолжить» серое без сейва */
menu_open(&menu, MENU_TITLE);

/* каждый шаг 1/30 с */
int ev = menu_tick(&menu, pad.Buttons, DT);         /* сырые PSP_CTRL_* (удерживаемые); фронты считает меню */
switch (ev) {
case MEV_NEW_GAME:  /* menu.chr: имя, пол, class_row (CharaInitParam 3000+i), gift_idx (2400+i), hair, атрибуты;
                       превью уже выгружено. Грузить зону. */ break;
case MEV_CONTINUE:  /* загрузить сейв */ break;
case MEV_QUIT:      sceKernelExitGame(); break;
case MEV_SETTINGS:  input.scheme = menu.set.scheme; /* яркость/камера - menu.set */ break;
case MEV_REST:      /* костёр: эстус, HP, респаун, сейв (меню остаётся открытым) */ break;
case MEV_LEVELUP:   /* view->attr/level/souls уже изменены */ break;
case MEV_USE_ITEM:  /* view->item[menu.ev_arg] */ break;
case MEV_TO_TITLE:  /* сейв, выгрузить зону, menu_open(&menu, MENU_TITLE) */ break;
case MEV_DIED_DONE: /* экран «ВЫ ПОГИБЛИ» дошёл до чёрного: перезагрузка у костра */ break;
case MEV_CLOSE: case MEV_LEAVE_BONFIRE: /* обратно в игру */ break;
}
if (!menu_screen(&menu) && (pressed & PSP_CTRL_START)) menu_open(&menu, MENU_PAUSE);
if (menu_blocks_game(&menu)) { /* ввод геймплея выключен; мир идёт дальше, как в DS1 */ }
/* смерть: menu_open(&menu, MENU_DIED); костёр (× у костра): menu_open(&menu, MENU_BONFIRE) */

/* кадр */
if (!menu_fullscreen(&menu)) { draw_world(); menu_draw_brightness(&menu.set); hud_draw(...); }
menu_draw(&menu);                                   /* в том же display list, после 3D; сам зовёт ui_begin/ui_end */
```

4. Данные для внутриигровых экранов — `MenuGameView` (`menu.h`): имя, класс, уровень, души, атрибуты, HP/энергия/вес/баланс/защита/атака, 19 слотов снаряжения (`MenuItem`: имя, описание, картинка, количество), до 32 предметов. Пока прогрессия этого не знает — `menu_fill_view_from_char(&menu, &view)` даёт стартовое состояние созданного персонажа (оружие, броня, эстус ×5, предметы класса, дар), а `menu_set_view(&menu, &view)` — подключает. Строки в `MenuItem` — указатели, меню их не копирует.
5. `menu.ashui` — отдельный от HUD `ui.ashui`: `menu_draw` начинает с `ui_begin()`, поэтому кэш шрифта src/ui не путается; если игра рисует HUD-текст **после** `menu_draw` в том же кадре — сначала `ui_begin()`.

## Классы, дары, внешность — откуда

- **Классы**: CharaInitParam 3000…3009 **[проверено]** (уровень и атрибуты в тест-логе совпадают с PARAM: Рыцарь 5 / 14 10 10 11 11 10 9 11). Названия — FMG 77/132020…132029 (в русской DSR: Воин, Рыцарь, Странник, Вор, Бандит, Охотник, **Волшебник**, Пиромант, **Клирик**, Нищий). Броня: HeadArmor…LegsArmor → EquipParamProtector.EquipmentModel → `parts/<HD|BD|AM|LG>_<A|M|F>_<модель>`; оружие: RightHandWeapon1 / LeftHandWeapon1 → EquipParamWeapon.WeaponModel → `WP_A_<модель>` на кости R_Weapon / L_Weapon. Охотник, Клирик, Нищий — без шлема (EquipmentModel 0), у них видны лицо и причёска.
- **Дары**: CharaInitParam 2400…2408 (предмет и количество), названия/описания — FMG 77/132050…, 132350…, иконки — EquipParamGoods.GoodIcon / EquipParamAccessory.MenuIcon.
- **Внешность** (урезано, без FaceGen): голова = `FC_<g>_0000` (кожа `Common_Body.tpf`) + лицевая часть `FG_A_0000` одним цветом кожи (медиана текстуры лица; в игре её текстуру генерирует FaceGen) + причёска `HR_<g>_<модель>` из строк EquipParamProtector 1000…1900 / 3100…3900. Набор 4 причёсок на пол и их цвет (в DSR волосы серые, цвет даёт шейдер) — **[придумал]**. Глаз нет.
- **Иконки предметов**: id → атлас `Icon<id//1000><(id%1000)//144>`, 12 столбцов, индекс `(id%1000)%144` — схема проверена глазами на 69 иконках в превью кука (оружие, броня, предметы, кольца) **[проверено глазами]**.
- **Стоимость уровня**: таблица 673…847 для уровней 1–11, дальше `0.02x³+3.06x²+105.6x−895` — **[версия: по памяти, в PARAM нет]**.
- HP/энергия/вес в `menu_fill_view_from_char` — заглушки **[версия]**: настоящие числа — у src/combat и src/progress.

- Не встроено в игру (см. рецепт выше); «Продолжить» только отдаёт событие — загрузка сейва у D/E.
