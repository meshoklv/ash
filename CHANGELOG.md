# Changelog

## v0.1.0 - first public release

- Engine in C99 on pspdev: `sceGu` renderer, GE skinning, VFPU animation, zone loading.
- Playable slice: title, character creation, Northern Undead Asylum, Asylum Demon, Firelink Shrine, menus, A/B saves.
- Souls-style combat module, original enemy AI on a Lua 5.0.3 VM, map event interpreter, items and progression.
- Hardware diagnostics (`log.txt`, `crash.txt`, hang watchdog); first run on a PSP Street E1000 (CFW 6.60 PRO-C): 26 minutes, no crash.
- Cooking tools (`tools/`) that convert your own legally owned game copy; no game data included.
